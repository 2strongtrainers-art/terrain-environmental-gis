Field-to-GIS workflow

Avenza → this app

Export map features from Avenza as KML/KMZ, GPX, CSV, or a Shapefile ZIP. On iPhone save the export to Files, then use Import GIS files here. This removes the need to route the file through Google Earth first.

Google Earth Pro → this app

Save Places as KML or KMZ, then import directly. Names, descriptions, points, lines and polygons are retained where the source format provides them.

ArcGIS / QGIS interoperability

Export GeoJSON or KML for ArcGIS Pro, ArcGIS Online, QGIS and Google Earth. GPX is available for compatible point/track workflows.

Terrain

USGS basemaps provide topo, imagery and shaded relief. A map tap queries USGS elevation and estimates local slope/aspect from nearby elevation samples. The slope/aspect estimate is a screening tool, not a survey-grade replacement for DEM/LiDAR analysis.

Current public layers

Historical fire perimeters use CAL FIRE FRAP Firep25_1 (released April 2026). State Responsibility Areas use SRA26_1. Fire Hazard Severity Zones combine the adopted 2024 SRA zones with the 2025 LRA recommendations. Watershed boundaries use USGS HUC10 data.

Privacy & cost

Project geometry is processed and autosaved in the browser. No account, paid API key, database or subscription is required for the MVP.
