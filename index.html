How this product is different

Goal: remove the manual Avenza → Google Earth → desktop GIS handoff for common screening work.

1. Define

Import field/GIS files or draw an area of interest. Names, descriptions and compatible attributes are retained.

2. Analyze

The app calculates project geometry and terrain screening, then checks live public fire-hazard, responsibility-area, fire-history and watershed services.

3. Review

Findings are translated into plain-language project intelligence with visible provenance and limitations.

4. Report / share

Generate a printable professional screening report, export GIS files, or create a read-only link containing the project geometry and latest analysis snapshot.

Privacy

The current market preview stores working projects locally in your browser. Share links encode project data into the URL you choose to send. No cloud account or database is used yet.
